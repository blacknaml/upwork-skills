# Contributing

Thanks for wanting to make these skills better. Small contributions count here: fixing one stale sentence is a real contribution, and if this is your first pull request ever, this repo is a good place for it.

## What we're looking for

- **Corrections.** Upwork changes things: Connects pricing, badge rules, search behavior. If a skill states something that's no longer true, that's the most valuable PR you can send.
- **Field results.** If you tried a skill's advice on a real job and something worked differently, open an issue and tell us what happened. Real outcomes beat theory.
- **Translations.** Any skill, any language. Bahasa Indonesia versions are a first-class goal, not an afterthought.
- **New skills.** More Upwork craft (pricing, portfolio prep, niche workflows) fits here. Other platforms deserve their own pack. Open an issue first so we agree on scope before you write.

## Your first pull request, step by step

1. **Fork** this repository (button at the top right).
2. **Edit the file** you want to change. For small text edits, you can do this entirely in the browser: open the file in your fork and click the pencil icon.
3. **Commit** with a short message saying what changed and why.
4. **Open a pull request** back to this repository. Plain language is fine. Tell us what you changed and, if it's a correction, how you know the new version is right.

Stuck on any step? Open an issue and say so. Teaching people to contribute is part of what this project is for.

## House rules

Every contribution follows these. PRs that break them get a friendly note and a request to revise, not a rejection.

1. **Plain human voice.** Write like you'd talk to another freelancer. No corporate filler.
2. **No invented statistics.** If you cite a number, link where it comes from.
3. **Sources cited.** Claims about how Upwork works should link to Upwork's own published guidance or clearly say "field experience."
4. **No client names or real rates in examples.** Anonymize everything. "A SaaS client" and "your hourly rate" are enough.
5. **No scraping or automation** that violates any platform's terms. These skills work on pasted text by design.
6. **English or Bahasa Indonesia** for discussion; skill translations can be any language.

## What happens after you submit

A maintainer reviews within a few days. Corrections and translations usually merge fast. New skills get a scope conversation first (that's why the issue-before-PR rule exists). Every merged contributor gets credited.
